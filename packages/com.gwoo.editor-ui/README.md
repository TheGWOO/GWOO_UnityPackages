# Editor UI

Reusable UI Toolkit controls and editor styling helpers for Unity editor tools.

## What's Included

- Small UI Toolkit controls such as buttons, toggles, cards, and separators.
- Shared USS styles and palette resources.
- Editor style helpers for applying the package theme to custom windows.

## Usage

Reference `GWOO.CustomUIElements` and `GWOO.CustomStyles.Editor`, then use the controls from `GWOO.UIElements` and style helpers from `GWOO.Editor.Utils` in your custom editor windows.
